
# Ассемблер учебной виртуальной машины — вариант №9

## 1. Описание проекта

Проект представляет собой CLI-ассемблер для учебной виртуальной
машины (УВМ).

Ассемблер принимает программу в формате YAML, проверяет
корректность команд и преобразует их во внутреннее
промежуточное представление.

## 2. Используемые технологии

- Python 3
- PyYAML
- unittest
- Git

## 3. Поддерживаемые команды

### 3.1. Загрузка константы — load_const

Поля:
- A = 3 (код операции)
- B = constant (17 бит)
- C = address (6 бит)

Размер команды: 4 байта.

### 3.2. Чтение значения из памяти — read_memory

Поля:
- A = 12 (код операции)
- B = offset (12 бит)
- C = destination (6 бит)
- D = base (6 бит)

Размер команды: 4 байта.

### 3.3. Запись значения в память — write_memory

Поля:
- A = 14 (код операции)
- B = address (32 бита)
- C = source (6 бит)

Размер команды: 6 байт.

### 3.4. Унарная операция — bswap

Поля:
- A = 6 (код операции)
- B = source (6 бит)
- C = destination (32 бита)

Размер команды: 6 байт.

## 4. Формат входного файла

Исходная программа записывается в YAML.

Пример:

```yaml
program:
  - command: load_const
    constant: 896
    address: 5

  - command: read_memory
    offset: 389
    destination: 42
    base: 3

  - command: write_memory
    address: 617
    source: 35

  - command: bswap
    source: 31
    destination: 416
```

## 5. Внутреннее представление

Каждая команда преобразуется в словарь.

Например:

```python
{
    "command": "load_const",
    "A": 3,
    "B": 896,
    "C": 5
}
```

Вся программа представляется списком таких словарей.

## 10. Формирование машинного кода

На втором этапе реализован транслятор промежуточного
представления в машинный код.

Для каждой команды выполняется упаковка полей A, B, C и D
в целое число с последующим преобразованием в байты.

Используется порядок байтов little-endian.

Размеры команд:

- load_const — 4 байта;
- read_memory — 4 байта;
- write_memory — 6 байт;
- bswap — 6 байт.

Результат записывается в двоичный файл.

Для проверки используется режим --test, который выводит
машинный код в шестнадцатеричном формате и размер
полученного бинарного файла.

### Запуск

```bash
python src/assembler.py tests/variant9.yaml result.bin
```

### Запуск в режиме тестирования

```bash
python src/assembler.py tests/variant9.yaml result.bin --test
```

### Проверка тестов

```bash
python -m unittest discover -s tests -v
```

## 11. Интерпретатор и операции с памятью

На третьем этапе реализован интерпретатор учебной виртуальной машины.

### Модель памяти

Используются три отдельных компонента:

- Память команд — хранит бинарную программу.
- Регистры — массив из 64 регистров.
- Память данных — хранит значения по адресам.

### Поддерживаемые операции

- Загрузка константы (load_const).
- Чтение значения из памяти (read_memory).
- Запись значения в память (write_memory).

Команда bswap будет реализована на этапе 4.

### Запуск интерпретатора

```bash
python src/interpreter.py program.bin dump.csv 0 100
```

Аргументы:

1. program.bin — бинарная программа.
2. dump.csv — файл дампа памяти.
3. 0 — начальный адрес дампа.
4. 100 — конечный адрес дампа.

Для загрузки начальных данных памяти используется
необязательный аргумент --init:

```bash
python src/interpreter.py program.bin dump.csv 200 202 --init tests/initial_memory.csv
```

### Тестовая задача

Реализована программа копирования массива из трёх элементов
из адресов 100–102 в адреса 200–202.

Исходные значения:

- 100: 11
- 101: 22
- 102: 33

Ожидаемый результат:

- 200: 11
- 201: 22
- 202: 33

Дамп памяти сохраняется в формате CSV.

## 12. Реализация арифметико-логического устройства

На четвертом этапе реализована команда bswap().

Команда выполняет изменение порядка четырех байтов
32-битного значения.

### Формат команды bswap()

- A = 6 — код операции.
- B — номер регистра-источника (6 бит).
- C — адрес памяти назначения (32 бита).
- Размер команды — 6 байт.

### Принцип работы

1. Из регистра, указанного полем B, считывается значение.
2. Проверяется допустимость 32-битного значения.
3. Выполняется изменение порядка байтов.
4. Результат записывается в память данных по адресу C.

### Пример

Исходное значение:

0x00012345

Результат:

0x45230100

Результат сохраняется в памяти по адресу 416.

### Запуск тестовой программы

```bash
python src/assembler.py tests/bswap.yaml bswap.bin
```

```bash
python src/interpreter.py bswap.bin bswap_dump.csv 416 416
```

### Проверка

```bash
python -m unittest discover -s tests -v
```
