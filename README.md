
# Ассемблер учебной виртуальной машины — вариант №9

## 1. Описание проекта

Проект представляет собой CLI-ассемблер для учебной виртуальной
машины (УВМ).

Ассемблер принимает программу в формате YAML, проверяет
корректность команд и преобразует их во внутреннее
промежуточное представление.

## 2. Используемые технологии

- Python 3
- PyYAML
- unittest
- Git

## 3. Поддерживаемые команды

### 3.1. Загрузка константы — load_const

Поля:
- A = 3 (код операции)
- B = constant (17 бит)
- C = address (6 бит)

Размер команды: 4 байта.

### 3.2. Чтение значения из памяти — read_memory

Поля:
- A = 12 (код операции)
- B = offset (12 бит)
- C = destination (6 бит)
- D = base (6 бит)

Размер команды: 4 байта.

### 3.3. Запись значения в память — write_memory

Поля:
- A = 14 (код операции)
- B = address (32 бита)
- C = source (6 бит)

Размер команды: 6 байт.

### 3.4. Унарная операция — bswap

Поля:
- A = 6 (код операции)
- B = source (6 бит)
- C = destination (32 бита)

Размер команды: 6 байт.

## 4. Формат входного файла

Исходная программа записывается в YAML.

Пример:

```yaml
program:
  - command: load_const
    constant: 896
    address: 5

  - command: read_memory
    offset: 389
    destination: 42
    base: 3

  - command: write_memory
    address: 617
    source: 35

  - command: bswap
    source: 31
    destination: 416
```

## 5. Внутреннее представление

Каждая команда преобразуется в словарь.

Например:

```python
{
    "command": "load_const",
    "A": 3,
    "B": 896,
    "C": 5
}
```

Вся программа представляется списком таких словарей.

## 6. Запуск программы

Установка зависимостей:

```bash
python -m pip install -r requirements.txt
```

Запуск ассемблера:

```bash
python src/assembler.py tests/variant9.yaml result.bin
```

Запуск в режиме тестирования:

```bash
python src/assembler.py tests/variant9.yaml result.bin --test
```

## 7. Запуск тестов

```bash
python -m unittest discover -s tests -v
```

## 9. Этапы разработки

Этап 1: перевод программы в промежуточное представление.

Формирование машинного кода, интерпретатор и выполнение
команд реализуются на последующих этапах проекта.

## 10. Формирование машинного кода

На втором этапе реализован транслятор промежуточного
представления в машинный код.

Для каждой команды выполняется упаковка полей A, B, C и D
в целое число с последующим преобразованием в байты.

Используется порядок байтов little-endian.

Размеры команд:

- load_const — 4 байта;
- read_memory — 4 байта;
- write_memory — 6 байт;
- bswap — 6 байт.

Результат записывается в двоичный файл.

Для проверки используется режим --test, который выводит
машинный код в шестнадцатеричном формате и размер
полученного бинарного файла.

### Запуск

python src/assembler.py tests/variant9.yaml result.bin

### Запуск в режиме тестирования

python src/assembler.py tests/variant9.yaml result.bin --test
