# Ассемблер и интерпретатор учебной виртуальной машины (УВМ)

**Вариант №9**

## 1. Описание проекта

Проект представляет собой разработку ассемблера и интерпретатора для учебной виртуальной машины (УВМ).

В рамках лабораторной работы реализованы:
- разбор исходной программы на языке ассемблера;
- преобразование программы во внутреннее представление;
- генерация машинного кода;
- выполнение машинных команд;
- модель памяти виртуальной машины;
- операция изменения порядка байтов `bswap()`;
- выполнение тестовой задачи над вектором из семи элементов.

## 2. Спецификация виртуальной машины

Для варианта №9 поддерживаются четыре команды.

| Команда | Код операции | Размер |
|---|---:|---:|
| Загрузка константы (`load_const`) | 3 | 4 байта |
| Чтение из памяти (`read_memory`) | 12 | 4 байта |
| Запись в память (`write_memory`) | 14 | 6 байт |
| Изменение порядка байтов (`bswap`) | 6 | 6 байт |

### 2.1. Загрузка константы

Команда загружает константу в регистр.

- A — код операции (4 бита).
- B — константа (17 бит).
- C — адрес регистра (6 бит).

Размер команды: 4 байта.

### 2.2. Чтение значения из памяти

Команда считывает значение из памяти и помещает его в регистр.

- A — код операции (4 бита).
- B — смещение (12 бит).
- C — адрес регистра назначения (6 бит).
- D — адрес базового регистра (6 бит).

Размер команды: 4 байта.

Адрес чтения определяется суммой значения базового регистра и смещения.

### 2.3. Запись значения в память

Команда записывает значение регистра в указанную ячейку памяти.

- A — код операции (4 бита).
- B — адрес памяти (32 бита).
- C — адрес регистра (6 бит).

Размер команды: 6 байт.

### 2.4. Операция bswap()

Команда выполняет изменение порядка четырёх байтов 32-битного значения.

- A — код операции (4 бита).
- B — адрес регистра-источника (6 бит).
- C — адрес памяти назначения (32 бита).

Размер команды: 6 байт.

Пример:

Исходное значение:

`0x00012345`

Результат:

`0x45230100`

## 3. Этап 1. Перевод программы в промежуточное представление

На первом этапе разработан ассемблер, выполняющий разбор исходной программы.

Реализованы:
- CLI-приложение ассемблера;
- входной файл с программой;
- выходной бинарный файл;
- человекочитаемый язык ассемблера на основе YAML;
- преобразование исходных команд во внутреннее представление;
- поддержка команд спецификации варианта №9;
- режим тестирования для проверки полей и значений команд.

## 4. Этап 2. Формирование машинного кода

На втором этапе реализовано преобразование промежуточного представления в машинный код.

Реализованы:
- кодирование команд;
- формирование двоичного представления;
- запись результата в бинарный файл;
- вывод размера двоичного файла;
- проверка байтовых последовательностей по спецификации УВМ.

Контрольные последовательности варианта №9:

**Загрузка константы:**

`03 38 A0 00`

**Чтение из памяти:**

`5C 18 EA 00`

**Запись в память:**

`9E 26 00 00 30 02`

**Команда bswap():**

`F6 81 06 00 00 00`

## 5. Этап 3. Интерпретатор и операции с памятью

На третьем этапе реализован интерпретатор машинного кода.

Реализованы:
- чтение бинарного файла;
- декодирование машинных команд;
- основной цикл интерпретации;
- раздельная память команд и данных;
- модель регистров;
- загрузка констант;
- чтение значений из памяти;
- запись значений в память;
- сохранение дампа памяти в формате CSV;
- возможность загрузки начальных данных из CSV.

Для проверки работы интерпретатора создана тестовая программа копирования массива из одной области памяти в другую.

Пример запуска:

```bash
python src/interpreter.py copy_array.bin copy_dump.csv 200 202 --init tests/initial_memory.csv
```

## 6. Этап 4. Реализация арифметико-логического устройства

На четвёртом этапе реализована операция `bswap()`.

Алгоритм работы:
1. Из указанного регистра считывается значение.
2. Проверяется, что значение помещается в 32 бита.
3. Выполняется изменение порядка четырёх байтов.
4. Результат записывается в указанную область памяти.

Для проверки создана тестовая программа `bswap.yaml`.

Исходное значение:

`0x00012345`

Результат:

`0x45230100`

Результат записывается по адресу 416.

Запуск:

```bash
python src/assembler.py tests/bswap.yaml bswap.bin
```

```bash
python src/interpreter.py bswap.bin bswap_dump.csv 416 416
```

## 7. Этап 5. Выполнение тестовой задачи

На пятом этапе решена тестовая задача варианта №9.

### 7.1. Основная задача

Реализована программа, которая выполняет операцию `bswap()` поэлементно над вектором длиной 7.

Результат каждой операции записывается в исходный вектор по тому же адресу.

Исходный вектор:

| Адрес | Значение |
|---:|---:|
| 100 | 1 |
| 101 | 2 |
| 102 | 3 |
| 103 | 4 |
| 104 | 5 |
| 105 | 6 |
| 106 | 7 |

Результат выполнения:

| Адрес | Значение после bswap() |
|---:|---:|
| 100 | 16777216 |
| 101 | 33554432 |
| 102 | 50331648 |
| 103 | 67108864 |
| 104 | 83886080 |
| 105 | 100663296 |
| 106 | 117440512 |

Для реализации тестовой задачи создан файл `vector7.yaml`.

Исходные данные хранятся в `vector7_memory.csv`.

Запуск ассемблера:

```bash
python src/assembler.py tests/vector7.yaml vector7.bin
```

Запуск интерпретатора:

```bash
python src/interpreter.py vector7.bin vector7_dump.csv 100 106 --init tests/vector7_memory.csv
```
